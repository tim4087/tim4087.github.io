# Tim4087_ — личный сайт

Статический сайт-портфолио: HTML + CSS + JS, без сборки.

**Открыть:** [tim4087.github.io](https://tim4087.github.io)

## Структура
- `index.html` — страница (RU / EN / ES, автоопределение языка)
- `styles.css` — стили
- `main.js` — параллакс фона, счётчики, переключение языков, защита контента
- `assets/` — аватар, рамка, обои

## Локальный запуск
```bash
python3 -m http.server 8080
# http://localhost:8080
```
